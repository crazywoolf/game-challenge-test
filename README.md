# Команда на бегу!

Браузерный пиксельный раннер с 41 героем, выбранным по идеям участников. В забеге можно собирать бонусы, перепрыгивать препятствия и выбирать один из четырёх фонов: луг, город, снег или космос. Игра работает на компьютере и телефоне.

## Запуск

Из папки проекта запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000>. Для прыжка используйте пробел или стрелку вверх, чтобы пригнуться — стрелку вниз. На телефоне доступны кнопки на экране.

## Изменить игру или сделать свою

- Чтобы изменить состав героев и идеи команды, отредактируйте `mock-character-data.json`.
- Чтобы добавить или изменить героя, отредактируйте список `characters` в `mock-character-data.json`: задайте имя, предпочтения и путь `image_path`. PNG положите в `images/community-characters/`. Если портрета нет, игра использует спрайт из атласа `images/characters/roster.png`.
- Чтобы поменять механику, оформление или фоны, редактируйте `index.html` — в нём находятся разметка, стили и код игры.
- Чтобы добавить картинки бонусов и препятствий для предпочтений, обновите `game-item-art.js`; набор PNG можно пересоздать командой `python3 generate_item_icons.py`.

Запустите игру локально и проверьте изменения. Чтобы опубликовать свою версию, загрузите копию проекта на GitHub и включите GitHub Pages для ветки `main`, папки `/ (root)`.
