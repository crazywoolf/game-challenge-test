# Game Challenge Test

Заготовка для совместной разработки цветного пиксельного раннера на встрече с детьми.

## Сейчас в проекте

- `mock-character-data.json` — восемь вымышленных анкет и сводка голосов за игровые элементы. Поля анкеты включают прическу, цвет волос и глаз, кофты, штанов и кроссовок.
- `images/characters/avatar-001.png`–`avatar-008.png` — отдельные игровые персонажи с прозрачным фоном.
- `images/characters/team-photo.png` — общая весёлая картинка команды.
- `character-image-requirements.md` — стиль и формат изображений для генерации следующих персонажей.
- `WORKSHOP-KIT.md` — анкета для чата и готовые промпты для персонажей, общей картинки команды, игры и публикации через GitHub Pages.
- `index.html`, `styles.css`, `game.js` — тестовая игра: выбор героя, прыжок, приседание, энергия и временный рост.

Открой `index.html` через локальный статический сервер или включи GitHub Pages для ветки `main` и папки `/ (root)`.
